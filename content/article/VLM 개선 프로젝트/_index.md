- **주요 기술 스택**: Python, OpenAI API, Gradio

- **담당 역할**

  - Vast.ai 플랫폼 활용 **LoRA 기반 파인튜닝 수행**
  - OpenAI Batch API 활용 **실생활 평가용 데이터 구축**
  - OpenAI Batch API 활용 **평가 지표 산출**
  - Gradio 활용 **데모 페이지 제작** 및 **시나리오 테스트**
